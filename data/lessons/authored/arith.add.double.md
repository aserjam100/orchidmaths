# Adding numbers within 100

To add two-digit numbers, add the tens and the ones separately, then put them together.

## Add the tens, then the ones

To work out 32 + 45:

Add the tens: 30 + 40 = 70.

Add the ones: 2 + 5 = 7.

Put them together: 70 + 7 = 77. So 32 + 45 = 77.

## When the ones make a new ten

To work out 36 + 27:

Add the tens: 30 + 20 = 50.

Add the ones: 6 + 7 = 13. That is 1 ten and 3 ones.

Put them together: 50 + 13 = 63. So 36 + 27 = 63.

## Check by counting on

Check 45 + 32 = 77 by counting on from 45.

Count on 3 tens: 55, 65, 75. Then count on 2 ones: 76, 77.

You end at 77, so the answer is right.
