# Multiplication word problems

When a story has equal groups and asks for the total, multiply.

## Find the equal groups

Read the story: Mei Ling has 4 boxes. There are 5 erasers in each of the boxes. How many erasers are there altogether?

Every box has the same number of erasers, so these are equal groups.

There are 4 groups, and there are 5 in each group.

## Draw a model

Draw one bar for each box, all the same length.

```
[ 5 ][ 5 ][ 5 ][ 5 ]
<------ ? -------->
```

The total is not known yet. 4 groups of 5 means multiply.

## Write the number sentence

Write the number sentence: 4 × 5 = 20.

Answer the question in words: There are 20 erasers altogether.

Type only the number, 20, in the answer box.
