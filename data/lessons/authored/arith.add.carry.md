# Adding with regrouping

When the ones add up to 10 or more, change 10 ones into 1 ten. This is called regrouping.

## Write the numbers in columns

To work out 47 + 38, write one number under the other. Tens go under tens and ones go under ones.

```
  4 7
+ 3 8
-----
```

Always start adding from the ones column on the right.

## Regroup 10 ones as 1 ten

Add the ones: 7 + 8 = 15.

15 ones is 1 ten and 5 ones. Write 5 in the ones column. Carry the 1 ten to the top of the tens column.

```
  1
  4 7
+ 3 8
-----
    5
```

## Add the tens

Now add the tens, including the ten you carried: 1 + 4 + 3 = 8.

```
  1
  4 7
+ 3 8
-----
  8 5
```

So 47 + 38 = 85.
