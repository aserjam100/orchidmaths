# Tens and ones

A two-digit number is made of tens and ones. Where a digit sits tells you what it is worth.

## Read tens and ones

The number 47 has two digits.

The 4 is in the tens place. It means 4 tens, which is 40.

The 7 is in the ones place. It means 7 ones, which is 7.

So 47 = 40 + 7.

## The value of a digit

What is the value of the digit in the tens place in 63?

The tens digit is 6. Six tens is 60.

So the value is 60, not 6. The value of a tens digit always ends in 0.

## Numbers with no tens

The number 8 has only one digit. It has no tens.

8 is the same as 08: 0 tens and 8 ones.

So the value of the digit in the tens place of 8 is 0.
