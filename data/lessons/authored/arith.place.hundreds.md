# Hundreds, tens and ones

A three-digit number is made of hundreds, tens and ones. Where a digit sits tells you what it is worth.

## Read hundreds, tens and ones

The number 347 has three digits.

The 3 is in the hundreds place: 3 hundreds is 300.

The 4 is in the tens place: 4 tens is 40.

The 7 is in the ones place: 7 ones is 7.

So 347 = 300 + 40 + 7.

## The value of the hundreds digit

What is the value of the digit in the hundreds place in 582?

The hundreds digit is 5. Five hundreds is 500.

So the value is 500. The value of a hundreds digit always ends in 00.

## Numbers with no hundreds

The number 64 has only two digits. It has no hundreds.

64 is the same as 064: 0 hundreds, 6 tens and 4 ones.

So the value of the digit in the hundreds place of 64 is 0.
